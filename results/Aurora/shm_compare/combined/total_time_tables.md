# Total time of MPI_Allgather, Allgather_radix_batch and Allgather_shm_view

Aurora, 102 processes per node. Total time is one call plus one read of the whole result by every process; each value is the median over the repetitions of that sum. MPI_Allgather runs with the system's default settings. Allgather_radix_batch shows the radix with the lowest total time for each message size. Message sizes of 256 KB and more were run on 1 to 16 nodes only, and with radix 102 only.

- **Whole result**: nodes × 102 × message size, the data every process receives.
- **Bold**: the fastest of the three.
- **Ratios**: below 1 means Allgather_shm_view is faster.
- **†**: the Allgather_radix_batch call time is at least 20% higher than in compare_big_20261104 for the same size. In this 64-node run a few processes were slow in stage 3 of Allgather_radix_batch while the average stayed the same; the cause is unknown, so do not use these values as they are.
